# 04. The 30-Day Client Fulfillment & Execution Manual

> **Purpose**: Internal operations manual detailing exactly how to execute and deliver the GEO remediation sprint once a client pays you $2,500 – $5,000.

---

## Week 1: Technical Infrastructure & Bot Accessibility

### Task 1.1: Audit & Update `robots.txt`
1. Access the client’s production `robots.txt` file (usually managed in Webflow, WordPress, Next.js, or Vercel).
2. Check for disallow rules blocking AI user agents:
   - `GPTBot` (OpenAI model training & SearchGPT)
   - `ChatGPT-User` (Real-time ChatGPT browsing)
   - `ClaudeBot` & `anthropic-ai` (Anthropic Claude)
   - `PerplexityBot` (Perplexity AI live citations)
   - `Google-Extended` (Gemini & Vertex AI)
3. Ensure these bots have explicit `Allow: /` rules.
4. Verify deployment using `curl -I https://client.com/robots.txt`.

### Task 1.2: Author and Publish `/llms.txt`
1. Copy the custom `/llms.txt` generated by the OmniGEO platform.
2. Verify the links in the file point to:
   - Client homepage
   - Pricing page
   - API / Developer docs
   - Core product feature matrix
3. Save the file directly in the public root directory (`/public/llms.txt` or `/static/llms.txt`).
4. Ensure it returns a `200 OK` status code with `text/plain` or `text/markdown` header.

### Task 1.3: Inject JSON-LD Knowledge Graph
1. Populate the client’s legal organization details into the JSON-LD snippet:
   - Full Legal Name, URL, official logo image URL.
   - Social profile URLs (`sameAs` array).
   - Crunchbase and Wikidata entity links.
2. Validate the markup using Google’s Rich Results Test tool: `https://search.google.com/test/rich-results`.
3. Deploy to the `<head>` of the root layout.

## Week 2: External Authority & Entity Linkage

### Task 2.1: Wikidata Entity Registration
1. Go to `https://www.wikidata.org/wiki/Special:NewItem`.
2. Set the Label to the Client Company Name.
3. Add the description: *"Software company specializing in [Niche]"*.
4. Add the following required statements (properties):
   - **instance of (P31)**: business (Q4830453) or software (Q7397)
   - **official website (P856)**: https://client.com
   - **inception (P571)**: Year founded
   - **country of origin (P17)**: Client country
5. Save the item and copy the generated entity ID (e.g., `Q12345678`).
6. Update the client's JSON-LD `sameAs` array to point to `https://www.wikidata.org/wiki/Q12345678`.

### Task 2.2: Reddit Citation Seeding Strategy
1. Identify the 3 most active subreddits where enterprise/SMB buyers research the client's category (e.g. `r/SaaS`, `r/webdev`, `r/sysadmin`, `r/startups`).
2. Search for existing threads comparing competitors (e.g., *"Alternative to [Competitor]?"*).
3. Draft a thoughtful, engineering-focused technical comment or case study highlighting the exact technical architecture where the client's tool outperforms legacy tools.
4. *Rule*: Never post low-quality spam links. Focus on objective architectural pros & cons. LLMs ingest long, upvoted analytical paragraphs.

### Task 2.3: Review Aggregator (G2 / Capterra) Optimization
1. Ensure the client's G2 and Capterra profiles are verified and claimed.
2. Review the categories client is listed under; ensure they match the exact prompt wording (e.g., *"B2B Lead Intelligence Software"* vs generic *"Sales Tool"*).
3. Have the client trigger an automated email to their top 50 happiest customers offering a $25 gift card or swag in exchange for a verified G2 review. (Perplexity relies heavily on recent 4.5+ star review counts).

## Week 3: Answer-First Content Architecture

### Task 3.1: The Inverted Pyramid Rewrite
1. Review the client’s top 5 landing pages.
2. Ensure the first paragraph answers the prompt directly:
   - **Bad**: *"In a fast-changing world where velocity matters, our journey began..."*
   - **Good**: *"[Client Name] is a [category] software platform that automates [specific workflow] for [target customer], cutting manual review time by 60% compared to [Competitor]."*
3. LLM retrieval engines (RAG and web search scrapers) prioritize sentences with explicit subject-predicate-object structure within the first 100 tokens.

### Task 3.2: Programmatic Competitor Comparison Matrices
1. Create a dedicated URL: `https://client.com/compare/[competitor-name]-alternative`.
2. Build an HTML `<table>` comparison grid with clear rows:
   - Feature / Capability
   - [Client Name] (Yes / No / Details)
   - [Competitor Name] (Yes / No / Limitations)
   - Pricing Structure
   - API & Extensibility
3. Avoid client-side Javascript accordion hiding for this table; keep it in raw server-rendered semantic HTML.

## Week 4: Benchmark Verification & Client Reporting

### Task 4.1: Re-Test Multi-Model Suite in OmniGEO
1. Run a new audit in OmniGEO using the same prompt suite tested in Week 1.
2. Note the improvements:
   - Has the Share of Voice increased from ~15% to 35%+?
   - Has Perplexity started citing the website or Reddit threads?
   - Is ChatGPT Search including the brand in the top 3 bullet points?

### Task 4.2: Deliver the Executive Progress Report
1. Print the updated OmniGEO audit report to PDF.
2. Schedule a 30-minute review call with the CMO or Founder.
3. Present:
   - Before vs. After Generative Share of Voice.
   - The unblocked bots and live `/llms.txt` deployment.
   - The newly seeded citation footprint on Reddit and Wikidata.
   - Transition to the ongoing $5,000/mo Retainer to maintain vigilance against competitor counter-attacks.
